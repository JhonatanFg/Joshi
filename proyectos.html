Mis Proyectos

Estos son tres pasos importantes que realicé al crear este sitio web.

Diseño Minecraft

Primero definimos el estilo visual inspirado en Minecraft: tipografía pixelada, fondos día/noche y tarjetas translúcidas con efecto gota de agua. El proceso incluyó configurar las fuentes, corregir rutas en Jekyll y aplicar glassmorphism con desenfoque mínimo para lograr un aspecto moderno.

Botón Día/Noche

Después añadimos el botón interactivo para alternar entre modo día y noche. El proceso fue ajustar el JavaScript para que guardara la elección en *localStorage, asegurando que la preferencia se mantuviera al navegar entre páginas. También se trabajó en transiciones suaves para que el cambio de fondo fuera fluido.

Animaciones fluidas

Finalmente integramos animaciones para dar vida al sitio. Usamos @keyframes para crear efectos de elasticidad al cargar y movimiento tipo agua en botones, tarjetas e imágenes. El proceso incluyó probar diferentes velocidades y transiciones hasta lograr un efecto natural y atractivo.

Proyecto Linux

Exploramos la configuración de entornos Linux, optimización de servidores y automatización con Bash. El proceso incluyó instalar distribuciones, personalizar el sistema, y crear scripts para agilizar tareas repetitivas. Este proyecto me permitió profundizar en la administración de sistemas y mejorar la eficiencia del desarrollo.
